\CWHeader{Лабораторная работа \textnumero 7 \enquote{Булев поиск}}

Требуется реализовать механизм выполнения поисковых запросов на основе ранее построенного булева индекса. Система должна обрабатывать булевы запросы, составленные из терминов (токенов) с использованием логических операторов.
\\ \\
Необходимо разработать и описать:
\begin{itemize}
    \item Формат представления поискового запроса
    \item Алгоритмы выполнения базовых операций над постинговыми списками (списками id документов):
    \begin{itemize}
        \item Пересечение (оператор \texttt{AND})
        \item Объединение (оператор \texttt{OR})
        \item Приоритеты (скобки)
    \end{itemize}
    \item Стратегию оптимизации порядка выполнения операций в сложных запросах.
\end{itemize}
